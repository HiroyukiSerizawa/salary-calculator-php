# 給与計算アプリ（PHP）

日本の給与計算を試算できる、PHP製のシンプルなWebアプリです。
実務に近いロジックを意識しながら、小規模業務システムのたたき台として開発しています。

---

## 概要

給与額から社会保険料・雇用保険料・所得税などを考慮し、手取り額の目安を算出します。

既存の給与計算サイトに対して、以下の点を改善することを目的としています。

* 広告なしでシンプルに使える
* ロジックを理解・カスタマイズできる
* 社内ツールとして転用しやすい

---

## 主な機能

* 支給額入力
* 社会保険料の計算
* 雇用保険料の計算
* 所得税の計算
* 手取り額の算出

---
