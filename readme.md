# 給与計算アプリ（PHP）

日本の給与計算をシミュレーションできる、PHP製のシンプルなWebアプリです。  
給与額から社会保険料・雇用保険料・所得税などを考慮し、手取り額の目安を算出します。

---

## 概要

このプロジェクトは、給与計算の仕組みをわかりやすく確認できるようにすることを目的として開発しています。

既存の給与計算サイトは便利な一方で、以下のような課題を感じることがあります。

- 広告が多く使いづらい
- ロジックの中身が見えない
- 自社向けにカスタマイズしにくい
- 実務に合わせた改修がしづらい

そこで本プロジェクトでは、**PHPでシンプルかつ拡張しやすい給与計算アプリ**を目指しています。

---

## 想定ユーザー

## 主な機能

- 支給額入力
- 社会保険料の計算
- 雇用保険料の計算
- 所得税の計算
- 手取り額の算出
- 将来的な制度改定への対応を見据えた構成
